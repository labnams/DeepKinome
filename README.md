# DeepKinome

This is the code repository for kinase-small molecule interaction prediction model, DeepKinome.

## Code description

**DeepKinome_building_source_code.ipynb** : the Jupyter notebook file (Python 3) to construct the prediction model and show validation results.

**MachineLearning_building_source_code_v2.ipynb** : the Jupyter notebook file (Python 3) to construct machine learning models and show validation results.

**CDRscan*.py** : the Python code files to construct the CDRscan model for kinase-small molecule interaction prediction.

**DeepIC50_building_source_code_v2.ipynb** : the Jupyter notebook file (Python 3) to construct the DeepIC50 model for kinase-small molecule interaction prediction.

**DeepKinome_toy_train/val/test_dataset.npz** : toy example datasets for deep learning model training, validation, and testing.

**Drug_chemical_descriptors.xlsx** : the file contains detailed descriptions of drug chemical properties used as features. These features were generated by PaDEL-Descriptor.

**feature_list.txt** : the file contains a feature list used for training models.

## Usage

Please refer to the annotations in DeepKinome_building_source_code.ipynb for details.

## Computer specification

The original DeepKinome model was developed under the following computer specification.

- Windows 10
- Python 3
- Keras 2.3.0
- TensorFlow-GPU 1.15.0
- NVIDIA Quadro RTX 5000
- RAM 64GB

## Q&A

**Q. Is the same TensorFlow version required for all models?**

No. The computer specification above refers to the original DeepKinome development environment, which used TensorFlow-GPU 1.15.0 and Keras 2.3.0.

The updated DeepIC50 (v2) code uses TensorFlow 2.x APIs, including `tf.keras.regularizers.L2()`, which is not supported in TensorFlow 1.15.0. The availability of this API has been confirmed in TensorFlow 2.14.0.

Therefore, the TensorFlow environment may differ depending on the source code being used.
